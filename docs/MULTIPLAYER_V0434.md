# v0.4.34 多人适配与验证

本轮保留已确认的卡牌增强及内讧减伤规则，新增角色和可选第四幕的多人适配。

## 规则

- 标准三幕路线，队伍至少有一位觉。任意觉领取遗落的心结，击败第三幕全部首领后全队进入庭院。其他模组增加的章节不被替换。多人路线依据队内领取的心结决定，不依赖各客户端的本地设置；预览捷径仅限单人。
- 所有角色进入庭院后各有独立剧情状态、一次入口回血、火堆回忆选项、同行选择和支援牌。回忆、支援资源及个人回合计数不会互相占用。多人只在本地角色旁显示同行，避免重复人物遮挡。
- 无实体目标为参战存活玩家数×4（单人4、双人8、三人12、四人16）；每人各6张战斗专用心结。任何人出牌均推进同一计数。完成时永久破除，并消耗所有玩家剩余心结，不修改永久牌组。
- 队友倒下时免去该玩家的4次需求，已有进度保留，每名玩家每场战斗仅免一次；复活后再次倒下不能重复降低需求。死亡被阻止时不降低目标。目标至少4；已完成时立即破除，避免队友牌消失导致无法完成。
- 暗示、内讧按施加者隔离。静庭只检查是否已有自己的内讧，队友的内讧不会阻止施加。
- 精神过载仍为共享资源。任意存活的噩梦能力持有者均可提前结算，仍每敌方轮次一次；反馈分别给每位能力持有者自己的格挡。
- 心念的本回合计数改用持有者自己的回合编号，支持某个玩家的额外回合；整场记忆计数继续保留。
- 第四幕多人生命与敌方格挡换算专门沿用原生第三幕首领倍率1.3，修复原生索引仅支持前三幕导致的异常；不改动其他章节的换算。
- 结局使用每位玩家自己的事件。远端事件回调不触发本地胜利结算。
